# ADR Template

## Status

## Context
What is the issue that we're seeing that motivates this decision?

## Question
What specific question are we trying to answer?

## Method
How did we investigate? (spike code, documentation review, measurements, etc.)

## Measurements / Findings
What did we observe? Include data, code snippets, screenshots.

## Result
What is the conclusion from the investigation?

## Decision
What is the change that we're proposing and/or doing?

## Consequences
What becomes easier or harder because of this change?
